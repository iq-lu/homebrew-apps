# iq-lu/apps

Homebrew casks for [IQ Studio](https://apps.iq.lu) Mac apps.

```sh
brew install --cask iq-lu/apps/mission-control-rename
```

| App | Cask | Version | Description |
| --- | --- | --- | --- |
| [Mission Control Rename](https://apps.iq.lu/mission-control-rename) | `mission-control-rename` | 1.1.4 | Names Mission Control desktops so spaces stop reading as Desktop 1, 2, 3 |

Casks are generated from the published release checksums; edit the generator in
the site repository rather than these files.
